# CoCan Web · 小电拼网页版

把 [CoCanBar](https://github.com/yangyihang96/CoCanBar) 那套 macOS 菜单栏 App 的功能搬进浏览器，**Windows / Linux / macOS 都能用**，不用装任何东西、不用签名、不用理会证书过期。

前端是四个静态文件，后端是一个零依赖的 Node 脚本（只用 Node 自带模块，不跑 `npm install`）。

---

## 它做什么

- **功率分布图**：就是 App 里那张标志性的图——五个端口卡排在上面，各自一根线弯到右下角机身对应的口，充电的线上还跑一道白虚线
- 看每路端口的实时功率、电压电流、协议、温度、充电时长
- 看整机总功率、充电曲线（30 分钟 / 2 小时）
- 改充电策略：自由流 / 睡眠充 / 魔幻充 / 性能模式 / 极速单充
- 单独开关某一路端口
- 温控模式（性能温控 / 安心温控）
- 状态屏：亮度、屏显模式、待机动画、整点报时
- 临时功率分配（整机 160 W 在五路之间手动分）
- 在充设备识别（厂商 / 型号 / PD 档位 / 请求电压电流）
- 暖色 / 冷色 × 浅色 / 深色，四套配色
- 扫描局域网自动找设备

## 它不做什么

和 macOS 版刻意不同的地方：

| | macOS 版 CoCanBar | 这个网页版 |
|---|---|---|
| 形态 | 菜单栏常驻 App | 浏览器标签页，关掉就没了 |
| 托盘 / 状态栏图标 | 有 | **没有**（网页做不到，也不打算做） |
| 开机自启 | 有 | 没有，要常驻自己加计划任务 |
| 系统通知 | 有 | 没有 |
| 数据 | 读设备 | 读设备，另存一份到浏览器 localStorage |
| 安装 | 要签名、7 天证书过期 | 打开网页就行 |

## 跑起来

### 1. 装 Node.js

需要 **Node 18 或更新**（18 / 20 / 22 都行）：<https://nodejs.org>

装完在终端里 `node -v` 能看到版本号就行。

### 2. 启动

**Windows**：双击 `start.bat`

**macOS / Linux**：

```bash
./start.sh
```

或者手动：

```bash
node server.mjs
```

看到这行就成功了：

```
小电拼网页版  http://127.0.0.1:7788
```

浏览器打开 <http://127.0.0.1:7788>。

换端口：`PORT=8080 node server.mjs`（Windows 上是 `set PORT=8080` 再运行）。

### 3. 添加设备

第一次打开是空的，点中间那个按钮：

1. **设备地址**：填 `192.168.x.x` 或者 `cp02s-xxxxxxxx.local`。不知道就去路由器后台看，或者点「扫描局域网」自动扫（要几秒）。
2. 点「添加」——它会先打一下设备首页，认出来是小电拼才让你保存，填错了会直接报错。
3. **MCP 地址**（可选）：不填也能看数据，但**开关端口、改策略、读温度这些要它**。在小程序「龙虾服务」里复制那串 `https://mcp.thecandysign.com/.../mcp`，整段粘进来就行，会自动挑出地址。

## 数据是怎么来的

两条完全独立的通道：

| 通道 | 地址 | 频率 | 拿到什么 |
|---|---|---|---|
| 局域网直读 | `http://<设备>/metrics.json` | 每 3 秒 | 五路端口的电压/电流/功率/状态、Wi-Fi 信号、芯片负载 |
| MCP | `https://mcp.thecandysign.com/...` | 每 15 秒 | 机器参数、端口详情、PD 状态、温控模式、屏幕设置、历史采样 |

为什么不直接从浏览器读 `metrics.json`？因为设备的 HTTP 服务**没有发 `Access-Control-Allow-Origin`**，浏览器跨域会直接拦掉。所以由本地这个 Node 脚本代劳——它同时也能把 `cp02s-xxx.local` 这种 mDNS 名字解析成 IP（浏览器里 `fetch` 一个 `.local` 名字要走 Happy Eyeballs，实测要 5 秒，脚本里查一次 DNS 就 0.1 秒）。

充电曲线：局域网每 3 秒采一次，前端攒成 **10 秒一个点**，保留 **2 小时**，存在浏览器 localStorage 里。刷新页面会恢复，换浏览器 / 清缓存就没了。MCP 那边还能拉到设备自己存的历史（拔电清空），首次进详情页会去补一次。

## 安全：`config.json` 里有什么

第一次添加设备后，同目录会生成 `config.json`：

```json
{
  "devices": [
    {
      "psn": "121903xxxxxx",
      "name": "桌子",
      "host": "cp02s-xxxx.local",
      "mcp": "https://mcp.thecandysign.com/xxxx/mcp?token=xxxx"
    }
  ]
}
```

**那串 MCP 地址里带着令牌，等于设备控制权。** 所以：

- 不要提交到 git（`.gitignore` 已经排除了）
- 不要发给别人、不要贴到截图里
- 创建时权限已经设成 `600`（只有你自己能读）

服务**默认只监听 `127.0.0.1`**，也就是只有这台电脑能打开，局域网里别人扫不到。想让手机也能看，用 `--lan` 启动：

```bash
node server.mjs --lan
```

这时会绑到 `0.0.0.0`，启动日志会打印真实局域网地址。**同一 Wi-Fi 下任何人都能打开这个页面，并且通过它开关你的充电器**——令牌本身拿不到（接口里是 `***`，MCP 调用由服务端代发），但能操作设备就等于控制权到手了。公共 Wi-Fi 上别这么干。

## 常见问题

**加了设备但一直是「离线」**
先确认电脑和充电器在同一个 Wi-Fi（很多路由器 2.4G / 5G 分开，充电器只连 2.4G）。然后在浏览器里直接开 `http://<设备地址>/metrics.json`，能出 JSON 说明设备没问题，是地址填错了。

**`cp02s-xxx.local` 打不开，IP 能开**
部分 Windows 没装 Bonjour，解析不了 `.local`。直接填 IP。

**MCP 一直失败**
MCP 地址会过期，重新从小程序复制一份。另外 MCP 是走公网的，断网就只剩局域网那部分功能——看功率照常，改设置不行。

**端口被占用**
`Error: EADDRINUSE`。换一个：`PORT=8081 node server.mjs`。

**曲线是空的**
刚打开只有几分钟的数据；页面关掉期间不采集。MCP 的历史补采要设备自己有记录（没断过电）。

**改了设置但界面没变**
设备执行要一两秒，界面等下一轮 MCP 轮询（最多 15 秒）才刷新。想立刻确认就直接看设备屏幕。

## 目录

```
cocan-web/
├── server.mjs          零依赖 Node 服务：静态文件 + 局域网代理 + MCP 中转 + 配置读写 + 网段扫描
├── start.sh            macOS / Linux 启动
├── start.bat           Windows 启动
├── config.json         你的设备（不入库，含令牌）
└── public/
    ├── index.html      顶栏 + 挂载点
    ├── style.css       四套配色（暖/冷 × 浅/深）、端口配色、卡片、图表
    ├── core.js         状态、常量、请求封装、轮询、历史采样、对话框
    ├── app.js          总览页、设备增删改、扫描、路由
    ├── diagram.js      功率分布图（端口卡 + 连线 + 机身，纯 SVG）
    └── detail.js       详情页：模式 / 端口 / 温控 / 状态屏 / 功率分配 / 曲线 / 在充设备
```

后端接口（都在本机，不需要鉴权，因为只听 127.0.0.1）：

| 接口 | 作用 |
|---|---|
| `GET /api/config` | 读配置（`mcp` 只返回 `***` 或空串，令牌不出本机） |
| `POST /api/config` | 写配置（原样回传 `***` 表示该设备的 MCP 地址不改） |
| `GET /api/lan?host=` | 代理设备的 `/metrics.json` |
| `GET /api/info?host=` | 解析设备首页里的 `window.__INFOZ`（PSN / 型号 / 固件） |
| `GET /api/scan` | 扫本网段，找出所有小电拼 |
| `POST /api/mcp` | 单次 MCP 工具调用 |
| `POST /api/mcp/batch` | 一次请求并发多个工具调用 |
